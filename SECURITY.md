# Security policy

Please do not file a public issue for a vulnerability that could expose secrets,
bypass an execution gate, cross an identity boundary, or delete the wrong VM,
NetBox record, or backup.

Report security concerns privately through GitHub's security-advisory interface
for this repository. Include the affected commit/version, impact, prerequisites,
and a minimal reproduction that contains no real credentials or institutional
data.

This alpha project does not promise a fixed response or remediation SLA. Do not
deploy it as a substitute for local security review, least-privilege tokens,
backups, change control, monitoring, or a tested recovery procedure.
